# Changelog

## 0.1.0-dev — 2026-08-20

Initial Drupal scaffold:

- native Drupal Media source for Piwigo image IDs;
- Media Library search and album browsing;
- visual, responsive photo grid replacing the initial table-oriented browser;
- semantic UI tokens mapped to Drupal/Gin variables with system-color fallbacks;
- accessible selected, hover, focus, disabled and forced-colors states;
- sticky functional filter and selection layers with restrained blur where supported;
- reduced-motion support and responsive container queries;
- Piwigo 16+ API-key support;
- local thumbnail cache;
- Piwigo derivative field formatter;
- administration form and configuration schema;
- Drupal 10.3/11 compatibility target.
